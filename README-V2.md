# Enterprise Agent Skills v2

This revision deepens the first three batches using progressive disclosure.

## Design
- SKILL.md = activation criteria, core workflow, decisions, anti-patterns, verification.
- references/ = deeper technical material loaded when needed.
- examples/ = concrete scenarios when useful.

This follows the progressive-disclosure approach used by mature agent-skill ecosystems: metadata first, instructions on activation, supporting resources on demand. See wshobson/agents architecture and skill documentation.

## Sources consulted
- PostgreSQL official documentation
- OWASP API Security Top 10 and OWASP Cheat Sheet Series
- Neon postgres-skills
- wshobson/agents skill architecture and backend architecture patterns

This repository synthesizes guidance rather than copying upstream skill files.
