# Interaction Accessibility Checklist

1. Can the entire task be completed by keyboard?
2. Is every interactive element semantically named?
3. Is focus visible and unobscured?
4. Does focus move sensibly after dialogs/navigation/errors?
5. Are status/error changes perceivable without relying on color?
6. Are custom widgets following the relevant ARIA interaction pattern?
7. Does zoom/reflow preserve task completion?
8. Does reduced-motion preference reduce nonessential motion?
