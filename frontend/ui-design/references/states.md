# UI State Matrix

A meaningful feature should consider:

| State | User needs |
|---|---|
| Loading | certainty that work is happening |
| Success | confirmation + next useful step |
| Empty | meaning + first action |
| No results | filter/search recovery |
| Validation error | correction |
| Server error | explanation + retry/recovery |
| Permission denied | clear access state |
| Timeout/offline | retry/reconnection path |
| Processing | current progress/state |
| Partial | what succeeded/failed |
