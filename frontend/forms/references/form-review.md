# Form Review Checklist

## Semantics
- Native controls where possible
- Explicit labels
- Correct input type
- Appropriate autocomplete
- Required/optional semantics

## Validation
- Client validation for feedback
- Server validation authoritative
- Errors associated with fields
- Helpful correction text
- User input preserved on recoverable failure

## Submission
- Duplicate submission prevented where necessary
- Progress communicated
- Success communicated
- Failure recoverable
- Keyboard path works

## Accessibility
- Visible focus
- Keyboard-only completion
- Accessible names
- Status/error announcements where required
- No color-only error indication
