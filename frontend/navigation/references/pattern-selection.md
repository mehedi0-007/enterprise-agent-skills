# Navigation Pattern Selection

## Primary navigation
Top-level product areas.

## Sidebar
Persistent multi-section SaaS/admin navigation.

## Tabs
Peer views within one context.

## Breadcrumb
Orientation in meaningful deep hierarchy.

## Context menu
Local secondary actions.

## Command/search
Fast supplement for large information architectures.

Do not choose a component because it is available; choose based on navigation semantics.
